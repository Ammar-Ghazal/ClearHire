# User-supplied candidates

`curated-profiles.json` is the combined profile input for `demo:import`: 25 profiles with resume or portfolio links and 28 saved repository selections across 17 profiles. The other eight profiles still need explicit repository selection. Three supplied profiles without resume links are preserved separately in `user_profiles_without_resume`. Restored from the original saved research on November 1, 2026; verification flags and historical commit references are preserved, not refreshed. Recorded commits are provenance only: live analysis grades each selected repository's current default-branch commit and stores only the result and the commit it graded, never the code.

`user-supplied-profiles.json` contains the 11 candidates supplied by Ammar, with their original names and links preserved. Three have no résumé link. Links and identity pairings have not been independently verified.
